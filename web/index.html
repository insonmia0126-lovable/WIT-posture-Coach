목격자

개인 기준에서 벗어난 자세가 지속될 때만 알리고, 알림 이후 회복을 확인합니다.

  • 포함: 기준 보정 · 지속 알림 · 회복 확인 · CSV
  • 후속: 모바일 · 조도 · 눈 피로 · 정면 카메라
  • PC 온디바이스 v0.1 · 서버 추론 없음

현재 상태

기준 기록

새 세션을 시작합니다.

A조건: 교정 피드백이 화면에 없습니다. 내부 판단은 CSV에만 남습니다. A의 alerts는 전달한 알림이 아니라 내부 경고 조건 횟수입니다.

모의 입력

90초 시연: 보정 → 짧은 움직임(알림 없음) → 6초 유지(알림) → 3초 복귀(회복) → 가림(중단, 회복 미집계) → CSV.

실험용 설정

  • 기준 기록 5초
  • 이탈 임계 +12° (수직 대비 귀–어깨 선)
  • 회복 범위 +8° 이하
  • 지속 알림 5초
  • 회복 유지 2초
  • 입력 공백 1.5초 → 관찰 중단

이 각도는 임상 CVA가 아닙니다. 어깨는 제7경추가 아니며, 촬영 각도와 몸통 움직임의 영향을 받습니다. 12°·5초는 동작 확인용 설계값입니다.

판단 흐름

  1. 카메라 또는 슬라이더 → 각도
  2. 개인 기준과 비교 (학습 모델이 알림을 결정하지 않음)
  3. 경계 구간에서 지속 타이머 초기화
  4. +12°가 5초면 알림 → +8°가 2초면 회복
  5. 가림·저신뢰·공백은 측정 불가. 중단된 에피소드는 회복 성공이 아님
