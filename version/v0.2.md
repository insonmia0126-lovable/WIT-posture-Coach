# v0.2 — 노트북 웹캠 온디바이스 시제품

- 태그: `v0.2`
- 날짜: 2026-10-13
- 복원: `git checkout v0.2`
- 실행: https://insonmia0126-lovable.github.io/WIT-posture-Coach/
- 로컬: 저장소 폴더에서 `start_windows.bat` 또는 `npm install --prefix app && npm run dev --prefix app` → http://127.0.0.1:43124

## 목적

Windows Chrome/Edge에서 **웹캠 시작 → 기준 등록 → 실시간 분석 → 지속 안내 → 복귀 → 결과**를 노트북만으로 시연하기 위한 버전입니다.

## 구성

| 항목 | 내용 |
|------|------|
| 앱 | `app/` React + TypeScript + Vite |
| 추론 | `@mediapipe/tasks-vision` 1.1.0, Pose Landmarker Lite, `app/public/`에 WASM·모델 |
| 지표 | 고개 좌우 기울기, 어깨 좌우 기울기, 얼굴–어깨 상대 위치(보조) |
| 실험값 | 기준 등록 7초, 이탈 지속 20초, 반복 안내 3분, 복귀 3초 |
| 시연 모드 | 단축 타이머 + 실시간 웹캠 미리보기 |
| 결과 | 표 요약, 고개/어깨/상체 안내 횟수, 개인 코치 3–4줄, 빨간 Pretendard Bold 면책 문구 |
| 기록 | 브라우저 학습 기록, 저장소 `learning/` |
| 배포 | GitHub Pages (`gh-pages`). 카메라 주소는 `127.0.0.1` 또는 공개 HTTPS |

## 개인정보

영상·좌표는 서버로 보내지 않습니다. 요약만 브라우저 localStorage에 저장합니다.
