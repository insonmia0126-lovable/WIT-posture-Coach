# v0.3 — 업무 중 허용 범위와 재측정

- 태그: `v0.3`
- 날짜: 2026-11-07
- 복원: `git checkout v0.3`
- 실행: https://insonmia0126-lovable.github.io/WIT-posture-Coach/
- 로컬: `start_windows.bat` 또는 `npm install --prefix app && npm run dev --prefix app` → http://127.0.0.1:43124

## 목적

같은 탭에서 측정을 반복할 수 있게 하고, 책상 업무 중 작은 자세 변화가 바로 기준 밖으로 잡히지 않게 한다.

## 변경

- 고개·어깨 이탈 14°, 복귀 9°. 상체 보조 이탈 0.22, 복귀 0.14. v0.2는 8° / 5° / 0.12 / 0.08.
- 기준 등록 7초, 이탈 지속 20초, 반복 안내 3분, 복귀 3초는 유지.

## 수정

- 세션을 끝내면 측정 비디오가 화면에서 빠지고, 다시 시작할 때 새 비디오에 카메라가 연결되지 않거나 인식 오류가 루프를 멈추던 경로를 고쳤다.
- 비디오 요소는 앱이 살아있는 동안 유지한다. 인식이 실패하면 루프를 계속하고 자세 모델을 다시 연다.

## 확인된 한계

이 수정은 코드 경로 기준이다. 피드백을 보낸 PC와 다른 PC에서 재측정이 되는지는 여기서 확인하지 않았다. 웹캠이 없는 환경이라 안내선이 다시 보이는지는 확인하지 않았다. 넓힌 허용 범위의 사람 대상 비율은 측정하지 않았다.

## 이전 버전에서의 이어짐

v0.2의 웹캠 온디바이스 측정, 개인 아이디, 브라우저 로컬 이력을 유지한다.
