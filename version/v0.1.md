# v0.1 — PC 연구 프로토타입

- 태그: `v0.1`
- 날짜: 2026-10-13
- 복원: `git checkout v0.1`

## 목적

중간발표에서 **기준 등록 → 지속 이탈 알림 → 회복 확인** 판단 흐름을 모의 입력과 PC 코드로 보여 주기 위한 버전입니다.

## 구성

| 항목 | 내용 |
|------|------|
| 실행 | `python -m wit.app` 또는 구 `web/` DEMO |
| 입력 | 각도 슬라이더(DEMO), 선택적 측면 카메라 |
| 지표 | 귀–어깨 2D 각도 (임상 CVA 아님) |
| 실험값 | 보정 5초, 이탈 +12°, 지속 5초, 회복 2초 |
| 검증 | `python run_tests.py` 상태 전이 8개 |
