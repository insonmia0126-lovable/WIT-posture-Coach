# 2분 시연 시나리오

1. 시작 화면에서 영상 외부 전송 없음을 읽고 **데모 시작** (0:00–0:15). 배너: 시뮬레이션 데이터.
2. 5초 기준 등록 완료 → 기준 범위 (0:15–0:25).
3. 고개 기울어짐이 지속되어 교정 안내 (0:25–0:50). “고개가 기준보다 기울었습니다.”
4. 복귀 후 “기준 자세에 가까워졌습니다” (0:50–1:10).
5. 종료 → 결과: 유효 시간, 안내 횟수, 복귀, 그래프. CSV는 실측과 분리됨을 말함 (1:10–1:40).
6. 웹캠 시작은 사용자 노트북에서 권한 허용 후 같은 흐름 (1:40–2:00). 실패 시 데모로 대체.

실사용 기본은 지속 10초다. 데모는 단축 설정임을 명시한다.
