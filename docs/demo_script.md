# 90초 데모 대본

1. **0–15초** “오늘은 상태 판단 흐름을 모의 입력으로 시연합니다.” DEMO 배너 확인. 새 세션, 기본 25°, 5초 보정.
2. **15–30초** 슬라이더를 50으로 약 1초 이동 후 25로 복귀. 경고 횟수가 늘지 않는지 확인. “잠깐 고개를 숙이는 동작은 지속시간 조건에서 제외합니다.”
3. **30–50초** 50으로 이동 후 6초 이상 유지. 알림 횟수 1. “기준에서 벗어난 상태가 이어질 때 알립니다.”
4. **50–65초** 25로 복귀 후 3초. 회복 확인·평균 회복 시간. “알림 이후 기준 범위로 돌아온 상태가 유지되는지 확인합니다.”
5. **65–80초** 50에서 다시 알림 후 모의 가림. 측정 불가. 가림 해제 후 25로 복귀해도 회복 성공으로 집계하지 않음.
6. **80–90초** CSV 저장. `mode=DEMO`, `feedback_enabled` 열 확인.

장애 시 DEMO 유지. 카메라 권한 오류는 장치 번호·OS 설정을 확인하고 해결되지 않으면 DEMO.
