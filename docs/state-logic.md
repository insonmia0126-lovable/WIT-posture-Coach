# 상태 판단

상태: 준비 / 기준 자세 등록 중 / 기준 범위 / 자세 변화 감지 / 교정 안내 / 측정 불가 / 일시정지

- 이탈 문턱(enter)과 복귀 문턱(exit)을 다르게 두어 깜빡임을 줄인다.
- 기본: 지속 10초, 반복 안내 30초, 복귀 3초. 설정에서 변경.
- 발표 데모 단축: 지속 2.5초, 복귀 1.2초. 화면에 시뮬레이션·단축 표기.
- 일시정지·탭 숨김 시간은 지속 시간에 넣지 않는다.
- 저신뢰·가림·화면 이탈·여러 사람은 측정 불가. 정상 범위로 집계하지 않는다.

구현: `app/src/engine/coach.ts`
