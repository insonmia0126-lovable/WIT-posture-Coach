# 예비 실험 양식 (파일럿)

연구 질문: 개인 보정·지속시간 기반 피드백이 피드백 없는 조건보다 자세 이탈 시간을 줄이는가? **현재 결과 미측정.**

- 참가자: 동의한 성인 5–10명 (탐색 목적. 임상 효과 입증 표본이 아님)
- 과제: 동일 책상 작업 각 5분
- A = 교정 피드백 표시 해제 (내부 판단만 CSV)
- B = 피드백 표시
- 순서 AB/BA 균형, 조건 사이 휴식
- 정답: 독립 측면 영상 판독. 앱 자체 지표로 앱 정확도를 검증하지 않음
- 통증 유발 자세 유지 지시 금지. 추가 촬영은 별도 동의·최소 보관·삭제 시점

| 지표 | A | B |
|------|---|---|
| 유효 관찰시간 (s) | 미측정 | 미측정 |
| 자세 이탈시간 비율 (%) | 미측정 | 미측정 |
| 독립 판독 기준 오경보 (회/분) | 미측정 | 미측정 |
| 알림 후 회복시간 (s) | — | 미측정 |
| 처리 지연 p50/p95 (ms) | 미측정 | 미측정 |
| 모바일 전력 | 대상 외 | 후속 |

이탈 비율 = 기준 이상 시간 ÷ 유효 관찰시간 × 100 (가림·보정 제외).
