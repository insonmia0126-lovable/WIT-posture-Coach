# 목격자 중간발표 구성안 (10분)

팀명·팀원·발표일은 제출 전 입력. 본 자료는 슬라이드 원문이 아니라 구성·대본이다.

| # | 시간 | 화면 | 말할 내용 |
|---|------|------|-----------|
| 1 | 0:30 | 제목, PC v0.1 / 모바일 후속 | 목격자는 자세가 달라졌음을 알려주고, 다시 돌아왔는지 확인하는 프로젝트입니다. 오늘은 측면 카메라 기반 기준 구현과 검증 계획을 설명하겠습니다. |
| 2 | 1:15 | PC 몰입 → 미인지 → 장시간 유지 | 대상은 책상에서 장시간 작업하는 사용자입니다. 모든 움직임을 나쁜 자세로 판단하지 않고, 개인 기준에서 벗어난 상태가 지속될 때만 알림을 주려 합니다. 통증 감소·유병률은 근거 없이 말하지 않습니다. |
| 3 | 0:45 | 포함/후속 | 첫 단계의 성공은 거북목 진단이 아니라, 입력이 끊겼을 때 잘못된 경고를 내지 않고 피드백 전후 변화를 기록하는 것입니다. |
| 4 | 1:10 | 연구 3편 비교 | A는 측정 입력, B는 구현 접근성, C는 피드백 설계를 참고했습니다. |
| 5 | 0:40 | 공백과 가설 | 새로운 자세 추정 모델을 제안하는 단계는 아닙니다. 기존 인식 결과를 언제·어떻게 전달해야 오경보를 줄이는지 검증합니다. |
| 6 | 1:10 | 카메라→MediaPipe→지표→규칙→CSV | 학습된 MediaPipe가 특징점을 추출하고, 이후 판단은 규칙 기반입니다. 서버 추론은 없습니다. |
| 7 | 0:50 | 5초 / +12° / 5초 / 2초 | 귀–어깨 선과 수직선의 각도입니다. 임상 CVA라고 부르지 않습니다. |
| 8 | 1:30 | 실행 앱, DEMO 배너 | 합성 입력으로 상태 흐름을 보여드립니다. |
| 9 | 1:20 | 구현 / 검증 / 미측정 | 8개 테스트는 판단 로직 검증이며 인식 정확도 100%가 아닙니다. |
| 10 | 0:50 | 현장 실측→A/B→모바일 | 발표 이후 촬영 조건을 고정한 소규모 실험으로 오경보와 이탈 시간을 확인합니다. |
