# 학습 기록 공간

버전(`v0.1`, `v0.2`, 이후)을 거치며 **목격자 결과에서 배운 점**을 여기에 모읍니다. 영상·얼굴 사진은 넣지 않습니다.

| 위치 | 무엇을 두나 |
|------|-------------|
| [insights.md](./insights.md) | 팀이 합의한, 버전에 걸친 학습 요약 |
| [entries/](./entries/) | 세션·시연 한 건마다의 메모 (템플릿 복사) |
| 앱 안 「학습 기록」 | 이 브라우저 localStorage. 결과 화면에서 자동 저장, 마크다운 내보내기 |

앱에서 보낸 파일은 `entries/`에 `YYYY-MM-DD-메모제목.md`로 저장하면 GitHub에서도 이력이 남습니다.

## 원칙

- 측정하지 않은 숫자(정확도, 치료 효과)를 만들지 않습니다.
- 시연(시뮬레이션)과 웹캠 실측을 섞어 해석하지 않습니다.
- 의료 진단이 아닙니다. 목격자는 질환을 진단하지 않습니다.
- API 키, 개인 식별 정보, 촬영 원본은 올리지 않습니다.
